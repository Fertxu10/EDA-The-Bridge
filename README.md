# EDA-The-Bridge

# ⚽ Análisis Exploratorio de Datos en Fútbol - "El fútbol bajo la lupa, análisis de factores que marcan la diferencia los últimos 25 años."

Este proyecto es un análisis exploratorio de datos (EDA) aplicado a partidos de fútbol profesional. El objetivo fue identificar patrones, tendencias y relaciones entre variables que pueden influir en el resultado de un partido.

## 📁 Contenido del Proyecto

- `notebooks/`: contiene los notebooks de análisis (EDA, limpieza, visualización).
- `funciones/`: contiene un archivo .py con algunas funciones creadas.
- `data/`: dataset utilizado en el análisis.
- `main/`: contiene el archivo main final.
- `resources/`: visualizaciones generadas a partir de las hipótesis.
- `presentacion/`: presentación final utilizada para exponer los resultados (formato .pdf o .pptx).
- `memoria`: memoria con la informacion de la presentacion un poco mas extensa.
- `making off`: un pequeño archivo con una explicacion pequeña sobre como se han obtenido las hipotesis .
- `README.md`: este archivo.

## 🎯 Objetivos del Análisis

- Explorar el impacto de variables como:
  - Posesión de balón
  - Tarjetas amarillas
  - Disparos al arco
  - Faltas cometidas
  - Minuto del primer gol
  - Rendimiento del portero

- Contrastar hipótesis populares en el ámbito futbolístico con datos reales.

## 📊 Hipótesis Analizadas

1. ¿Tener más posesión aumenta las probabilidades de ganar?
2. ¿Recibir más tarjetas amarillas afecta negativamente al resultado?
3. ¿El equipo que recibe más disparos a puerta tiene más probabilidades de perder?
4. ¿Qué tan importante es tener un buen portero?
5. ¿El equipo que anota primero suele ganar?
6. ¿Jugar de local ofrece una ventaja significativa?
7. ¿Cometer más faltas incrementa la probabilidad de perder?

## 🧠 Conclusiones Generales

- No siempre el que anota primero gana.
- Jugar de local tiene cierta ventaja estadística.
- Las faltas no son garantía de derrota, pero pueden influir.
- La intuición futbolística muchas veces no coincide con los datos.
